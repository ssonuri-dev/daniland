# 다니랜드 🐾

5살 아이가 그날 배운 걸 게임으로 복습하는 웹사이트.

🔗 **https://ssonuri-dev.github.io/daniland/** — 링크만 있으면 폰·태블릿에서도 바로 됩니다.

한 수업 데이터로 여러 가지 놀이를 할 수 있습니다. 그림이 있는 수업은 다음 **세 가지**입니다.

| 놀이 | 하는 법 | 연습되는 것 |
|---|---|---|
| 👂 **듣고 찾기** | 소리를 듣고 맞는 그림을 누릅니다 | 듣기 |
| 🔤 **글자 찾기** | 그림을 보고 맞는 글자를 누릅니다 | 읽기 |
| 🃏 **짝 맞추기** | 같은 그림 두 장을 찾습니다 (뒤집을 때마다 단어를 읽어 줍니다) | 기억·반복 |

요일처럼 **그림으로 보여줄 수 없는 말**을 위한 놀이도 두 가지 있습니다.

| 놀이 | 하는 법 | 연습되는 것 |
|---|---|---|
| 🔊 **듣고 단어 찾기** | 그림 없이, 소리를 듣고 맞는 영어 단어를 누릅니다 | 듣기·읽기 |
| 📅 **순서 맞추기** | 아무 요일에서 시작해 차례대로 눌러 한 줄을 완성합니다 | 순서·읽기 |

## 새 수업 추가하기 ⭐

`js/data.js` 파일을 열어서 배열에 항목 하나만 추가하면 됩니다.
홈 화면 카드와 게임 화면은 자동으로 만들어집니다.

```js
{
  id: 'en-vehicles',        // 다른 수업과 겹치지 않는 영문 이름
  subject: '영어',           // 홈에서 묶일 과목 이름
  group: '단어 공부',        // 그 과목 안의 묶음 이름 (아래 '과목 안의 묶음' 참고)
  title: '탈것',             // 카드 제목
  icon: '🚗',               // 카드 아이콘
  lang: 'en-US',            // 읽어줄 언어 ('ko-KR' 이면 한국어로 읽어요)
  items: [
    { emoji: '🚗', word: 'car',   ko: '자동차' },
    { emoji: '🚌', word: 'bus',   ko: '버스' },
    { emoji: '✈️', word: 'plane', ko: '비행기' },
    { emoji: '🚂', word: 'train', ko: '기차' }
  ]
}
```

- `emoji` : 화면에 보여줄 그림. **여러 개 반복해도 됩니다** (예: `'🍭🍭🍭'` → 개수 세기 문제)
- `word`  : 소리로 읽어줄 말. `lang` 언어로 발음됩니다.
- `ko`    : 정답을 맞췄을 때 카드에 함께 보여줄 우리말 뜻
- 👩‍🏫 🧑‍🚒 처럼 **여러 그림이 합쳐진 이모지도 한 개로 세어** 크게 보여 줍니다.
- `word` 가 길면(`police station`) 카드 크기에 맞춰 글자가 저절로 작아집니다.
  한글은 알파벳보다 두 배 넓게 세므로 `보스니아 헤르체고비나` 같은 이름도 칸에 맞습니다.

**글자를 우리말로 하고 싶으면** `wordKo: true` 를 적습니다. 국기 수업이 그렇습니다 —
놀이 세 가지 모두 **우리말 나라 이름**으로 보여 주고 우리말로 읽어 줍니다.
`word` 에 적은 영어 이름은 데이터에 남고 화면에만 안 나옵니다.

```js
{
  id: 'world-flags',
  subject: '세계',
  title: '국기',
  icon: '🚩',
  lang: 'en-US',
  wordKo: true,             // 세 놀이 모두 우리말로
  items: [
    { emoji: '🇰🇷', word: 'South Korea', ko: '대한민국' }
  ]
}
```

**요일처럼 그림이 없는 수업**은 `emoji` 를 비우고, 쓸 놀이를 `modes` 에 적습니다.

```js
{
  id: 'en-months',
  subject: '영어',
  title: '달 이름',
  icon: '🗓️',
  lang: 'en-US',
  modes: ['sound', 'order'],   // 듣고 단어 찾기 · 순서 맞추기
  cycle: true,                 // 12월 다음은 다시 1월 (돌고 도는 차례)
  items: [
    { word: 'January',  ko: '1월' },
    { word: 'February', ko: '2월' }
  ]
}
```

`modes` 를 안 적으면 그림이 있는 수업은 놀이 세 가지, 그림이 없는 수업은 위 두 가지가 나옵니다.
**순서 맞추기는 `items` 에 적은 차례가 그대로 정답**이 되니 순서대로 적어 주세요.
- 시작하는 자리는 **매번 달라집니다.** 늘 첫 번째 말부터 나오면 지루하니까요.
- `cycle: true` 를 적으면 요일·달처럼 **끝을 지나 처음으로 이어집니다**
  (토 · 일 · 월 · 화 …). 1, 2, 3 처럼 되돌아가지 않는 말에는 적지 마세요.
- 항목이 4개 이상이면 '보통' 난이도가, 6개 이상이면 '어려워요'까지 잘 동작합니다.

이모지는 [emojipedia.org](https://emojipedia.org) 에서 찾아 복사해 붙여 넣으면 됩니다.

### `js/data.js` 의 배열 세 개

| 배열 | 무엇 | 예 |
|---|---|---|
| `SUBJECTS` | 홈에 큰 카드로 나올 **과목** (적힌 순서대로 놓입니다) — 과목 안의 묶음(`groups`)도 여기 | 영어 · 수학 · 한글 · 세계 · 놀이 |
| `LESSONS` | 위 수업 데이터로 도는 카드 | 과일 · 동물 · 색깔 |
| `PAGES` | 수업 데이터 없이 따로 만든 카드 | 세어 보기 · 빼기 · 백 판 놀이 · 그림 그리기 |

`LESSONS` 과 `PAGES` 는 과목 페이지에서 **같은 층**입니다. 둘 다 `subject` 에 적은 과목으로
들어가고, 둘 다 **'무엇을 배우나'** 를 제목으로 씁니다.
**'어떻게 풀까 · 얼마나 어렵게'** 는 카드를 누른 뒤 시작 화면에서 고릅니다.

> `SUBJECTS` 에 없는 이름을 `subject` 에 쓰면 홈 맨 뒤에 과목이 하나 새로 생깁니다.
> 순서와 아이콘을 정하고 싶으면 `SUBJECTS` 에도 한 줄 추가해 주세요.

### 과목 안의 묶음 (`group`)

카드가 많아진 과목(영어 · 수학 · 한글)은 **한 층 더** 나뉩니다 — 과목 카드를 누르면 먼저 묶음 카드가 나오고,
묶음을 누르면 그 안의 수업·놀이 카드가 나옵니다. 세계·놀이처럼 묶음이 없는 과목은 지금처럼 카드가 바로 나옵니다.

| 과목 | 묶음 |
|---|---|
| 영어 | 📖 단어 공부 (과일 · 동물 · …) · 📚 책 읽기 (책마다 카드 한 장 — `js/books.js` 에 책을 더하면 카드도 늘어납니다) · 🚏 문장·놀이 (마을 지도 · 할머니 섬 여행 · 탈것 타기) |
| 수학 | 🔢 세기·비교 · ➕ 더하기·빼기·곱하기 · 💯 수 순서·백 판 |
| 한글 | 📖 낱말 공부 · ✏️ 글자 쓰기·만들기 |

묶음은 `SUBJECTS` 의 그 과목에 `groups` 로 적혀 있고, 카드는 `group` 에 묶음 이름을 적어 들어갑니다.
새 수업을 넣을 때 **`group` 을 꼭 적어 주세요** — 안 적으면 '그 밖에' 라는 묶음이 생겨 거기로 갑니다.
`groups` 에 없는 이름을 쓰면 그 이름으로 묶음이 맨 뒤에 새로 생깁니다.

게임 페이지의 주소(`play.html?lesson=…`, `ride.html` 등)는 묶음과 상관없이 그대로입니다.
바뀌는 건 목록 페이지뿐입니다 — `subject.html?name=영어&group=단어 공부`.

## 게임에 들어간 것들

- **놀이 고르기 + 난이도** — 시작 화면에서 놀이 방식과 난이도(보기 2~6개 / 짝 3~8개)를 고릅니다.
- **⭐ 별** — 한 번에 맞히면 별 1개. 틀린 카드는 흐려지고 다시 들려줍니다.
- **🔊 다시 듣기** — 몇 번이든 다시 들을 수 있어요.
- **글자 보기** — 듣고 찾기에서 글자 없이 소리만으로 할지, 철자도 같이 볼지 고를 수 있어요.
- **최고 기록** — 수업별 최고 별 개수가 과목 페이지의 카드에 표시됩니다. (이 기기에만 저장)
- **뒤로 가기** — 놀이 화면 왼쪽 위 **←** 는 방금 지나온 과목 페이지로 돌아갑니다.
  (거기서 🏠 를 한 번 더 누르면 첫 화면입니다. 아이가 놀이 하나 끝내고 옆 놀이로 넘어가는 길이
  제일 짧아야 해서 이렇게 두었습니다)
- 카드 크기와 열 수는 **창 크기에 맞춰 자동으로 정해집니다.** 어떤 놀이든 스크롤 없이 한 화면에
  들어오고, 줄이 고르게 채워지는 배치를 우선합니다 (예: 8짝은 4×4).
- PC에서는 **숫자키 1~8** 으로도 고를 수 있습니다.

## 🎤 목소리 고르기 (어른용)

게임 화면 아래 **🎤 목소리** 버튼을 누르면 이 기기에서 쓸 수 있는 목소리 목록이 나옵니다.
눌러서 들어보고 고르면 그 목소리로 저장됩니다. **말하기 속도**도 함께 조절할 수 있어요.

- 목록은 자연스러운 순서로 정렬됩니다. 맨 위 **‘추천’** 이 대체로 가장 사람 같습니다.
  (이름에 `Natural`, `Neural`, `Online`, `Google` 이 붙은 목소리가 품질이 좋습니다)
- 윈도우 기본 목소리(`Microsoft Zira`, `David` 등)는 딱딱한 편입니다.
  **엣지(Edge)에서 열면** `Microsoft Ava Online (Natural)` 같은 훨씬 자연스러운 목소리를 쓸 수 있어요.
- 온라인 목소리는 인터넷이 필요합니다. 연결이 끊기면 자동으로 다음 목소리로 넘어갑니다.
- 목소리를 추가하려면: 윈도우 **설정 → 시간 및 언어 → 음성 → 음성 추가**

## 🔢 수학

홈에서 **🔢 수학** 을 누르면 카드 여덟 장이 나옵니다. 영어·한글 수업 카드와 같은 층이라
**누르면 바로 그 놀이가 시작**됩니다. 수업 데이터와 상관없이 **문제를 매번 새로 만들어 냅니다.**

여덟 장은 `numbers.html` 한 화면을 함께 쓰고, 마지막 **백 판 놀이** 만 따로 만든 화면입니다.

| 카드 | 하는 법 | 숫자 범위 |
|---|---|---|
| 🔢 **세어 보기** | 그림이 몇 개인지 숫자를 고릅니다 | 1~5 / 1~10 / 1~20 |
| 🍎 **같은 개수 찾기** | 숫자를 보고 그만큼 있는 그림을 고릅니다 | 1~5 / 1~10 / 1~20 |
| ⚖️ **더 많은 것** | 두 묶음 중 많은 쪽을 고릅니다 | 1~5 / 1~10 / 1~20 |
| ➕ **더하기** | 🍎🍎 ➕ 🍎 = ? (합이 범위를 넘지 않게 나옵니다). 그림 밑에 `2 + 1 = ❓` 식이 같이 나오고 맞히면 답이 채워집니다 | 1~5 / 1~10 / 1~20 |
| ➖ **빼기** | 있던 것 중 몇 개에 ✖ 가 씌워집니다. 몇 개 남았을까요? 식은 `3 − 2 = ❓` | 1~5 / 1~10 / 1~20 |
| ✖️ **곱하기** | 같은 개수가 든 상자가 여러 개 — **2개씩 3묶음 = 2 × 3**. 보기에는 '한 묶음 더·덜' 한 수가 섞여 나옵니다 | 답 1~9 / 1~25 / 1~50 |
| 🪜 **수 순서** | `6 7 ❓ 9` 에서 빠진 수를 찾습니다 (가끔 거꾸로 셉니다) | 1~20 / 1~50 / 1~100 |
| 🔁 **패턴 잇기** | 🍎🍌🍎🍌🍎 다음에 올 그림을 고릅니다 | (숫자를 안 써서 단계가 없습니다) |
| 💯 **백 판 놀이** | 아래 표를 보세요 | 놀이마다 다릅니다 |

**그림은 다섯 개씩 줄을 맞춰 놓습니다.** 스무 개도 한눈에 세이고, 세다 보면
5 · 10 · 15 로 뛰어 세는 감각이 저절로 붙습니다.

**더하기·빼기·곱하기는 시작 화면에서 문제를 어떻게 보여 줄지 고릅니다** — 🍎 **그림** (그림만) ·
🔢 **식** (`6 + 3 = ❓` 만 크게, "6 더하기 3은 얼마일까요?" 하고 읽어 줍니다) · 🍎🔢 **그림 + 식** (둘 다, 기본).
세 놀이가 같은 설정을 씁니다.

놀이는 **수학 페이지에서 카드로 한 번만 고릅니다.** 그래서 시작 화면에는 무슨 놀이인지와
**숫자 범위**만 나와요 (패턴 잇기는 그것도 없습니다). 다른 놀이를 하려면
**← 다른 놀이 고르기** 로 수학 페이지에 돌아갑니다 (결과 화면에도 같은 버튼이 있습니다).

**숫자 범위는 놀이마다 따로 기억합니다.** 수 순서를 1~100 으로 해 두어도
세어 보기는 원래 고르던 대로 남습니다.

문제와 정답은 한국어로 읽어 줍니다 ("다섯 개를 찾아요", "모두 몇 개일까요?").
보기 숫자는 정답 근처에서 고르기 때문에 찍어서 맞히기 어렵습니다.
최고 기록은 놀이별로 남아 홈 카드에 ⭐ 로 표시됩니다.

## 💯 백 판 놀이

1 부터 100 까지가 **열 칸씩 열 줄**로 놓인 판(백 판)입니다. 100까지 세는 아이가
다음으로 배우는 것 — 뛰어 세기, 줄과 칸으로 수 읽기, 앞뒤 수 — 을 여기서 합니다.

| 놀이 | 하는 법 | 고르는 것 |
|---|---|---|
| 👟 **뛰어 세기** | 몇씩 뛸지 고르고 다음 수를 고릅니다 (`12 다음은 무슨 숫자일까요?`). **100 까지 갑니다** — 3씩이면 33문제, 10씩이면 10문제, 20씩이면 5문제. 지나온 칸이 계속 칠해져서 **5씩 뛰면 두 줄, 10씩 뛰면 한 줄**로 서는 것이 눈에 보입니다 | **− +** 로 2~20 중 아무 수나 (3씩, 7씩, 13씩 …) |
| 📍 **여기는 몇?** | 깃발이 꽂힌 칸의 수를 맞힙니다 | 수가 다 보이기 / 줄 첫 수만 보이기 |
| ↔️ **앞뒤 수** | 바로 앞·바로 뒤 수를 고릅니다. `49 → 50` 처럼 **줄이 바뀌는 자리**가 일부러 자주 나옵니다 | 1~50 / 1~100 |

놀이는 마을 지도·세계 지도처럼 **시작 화면에서 고릅니다.**

> **판의 칸은 눌러도 반응하지 않습니다 — 일부러 그렇게 두었습니다.**
> 폰에서 한 칸이 37px 밖에 안 돼 손가락으로 정확히 누를 수가 없어요.
> 판은 보여 주기만 하고, 답은 **판 아래 큰 숫자 카드**에서 고릅니다.

## 🚏 탈것 타기

홈에서 **🔤 영어** 안에 있습니다. 탈것 낱말을 배운 뒤 이어진 수업 — **탈것마다 '타다' 의 전치사가 다릅니다.**

| | 탈것 | 왜 |
|---|---|---|
| **get on** | bus · train · plane · ship · subway · bike · motorcycle · scooter | 서서 걸어 다닐 만큼 크거나, 자전거처럼 걸터앉는 것 — **올라타요** |
| **get in** | car · taxi · truck · helicopter | 몸을 숙여 들어가 앉는 것 — **들어가 앉아요** |

내릴 때는 짝이 정해져 있습니다 — on 으로 탔으면 **get off**, in 으로 탔으면 **get out of**.

길가 풍경에 탈것이 오른쪽에서 와서 다니 옆에 서면 아이가 고릅니다. 맞히면 **다니가 진짜로 그렇게 탑니다** —
on 이면 지붕 위에 올라타고, in 이면 안에 들어가 머리만 내밉니다 — 그리고 길이 흘러가며 떠납니다.
전치사의 뜻이 그림으로 보이는 것이 이 놀이의 핵심입니다.

시작 화면에서 놀이 세 가지 중 하나를 고릅니다.

| 놀이 | 하는 법 | 연습되는 문장 |
|---|---|---|
| 🚏 **타기** | `Get ___ the bus.` 를 보고 **on / in** 두 장 중 고릅니다 (8문제) | Get on the bus. / Get in the car. |
| 💬 **문장 고르기** | 탈것이 오면 문장 넉 장 중 맞는 것을 고릅니다 — `Get on the bus.` `Get in the bus.` `Get on the car.` `Get in the car.` (8문제) | 같은 문장, 이번엔 통째로 |
| 🔁 **타고 내리기** | on / in 으로 타고, 다 오면 **off / out of** 로 내립니다 (4대 × 2 = 8문제) | Get off the bus. / Get out of the car. |

- **한 판에 on 탈것과 in 탈것이 넉 대씩** 나옵니다. in 이 훨씬 드물어서 그냥 섞으면 'on 만 누르면 거의 맞는' 놀이가 되기 때문입니다.
- 틀리면 카드가 흐려지고 **까닭**이 뜹니다 (`🚗 몸을 숙여 들어가 앉는 탈것은 in`). 다시 고를 수 있습니다.
- 한 번에 맞히면 ⭐ 하나. 최고 기록은 놀이별로 남고, 그중 제일 잘한 기록이 영어 페이지 카드에 ⭐ 로 표시됩니다.
- 그림 파일이 없습니다 — 하늘·나무·길은 전부 디자인 파일(`css/style.css`)로 그린 것이라 바꿀 그림이 없습니다.

### 탈것을 더하거나 빼고 싶다면

`js/ride.js` 위쪽 `RIDES` 에 한 줄씩 있습니다 — `prep: 'on'` 인지 `'in'` 인지만 맞게 적으면 됩니다.
boat 는 일부러 뺐습니다 (작은 배는 get in, 큰 배는 get on 이라 답이 갈립니다).

## 🇸🇪 스웨덴

홈에서 **🌍 세계** 안에 있습니다. 세계 지도가 나라 열두 곳을 얕게 훑는다면, 여기서는 **스웨덴 한 나라만 깊이** 봅니다.
카드를 누르면 위 판에 **실제 사진**(`sweden/` 폴더, 16장)과 이야기가 나오고, 사진을 누르면 화면 가득 커집니다.
**폰에서는** 위 판 대신 카드를 누르면 사진과 이야기가 **화면 가득 팝업**으로 뜹니다 (✕ 닫기로 카드로 돌아옴) —
폰 폭에서는 판 옆 사진이 너무 작고, 판을 키우면 카드 18장이 밀려 스크롤이 생기기 때문입니다.
다른 나라를 더하고 싶으면 `js/sweden.js` 를 복사해 이야기와 퀴즈만 바꾸면 됩니다.
읽어 주는 말은 **우리말**이고, 스웨덴 말(Hej! · fika · Sverige …)은 우리말 뒤에 한 번 더 읽어 줍니다
(기기에 스웨덴어 목소리가 없으면 조용히 건너뜁니다 — 읽는 법은 우리말 안에 이미 있습니다).

시작 화면에서 놀이 세 가지 중 하나를 고릅니다.

| 놀이 | 하는 법 | 점수 |
|---|---|---|
| 🔎 **알아보기** | 카드 열여덟 장 — 국기 · 위치 · 수도 스톡홀름 · 왕과 공주 · 긴 겨울과 백야 · 오로라 · 순록과 사미 사람들 · 숲과 호수 · 삐삐 · 달라 말 · 미트볼 · 피카 · 토요일 사탕 · 노벨상 · 루시아 축제 · 미드솜마르 · 바이킹 · 스웨덴 말 인사. 누르면 위 판에 이야기가 나오고 읽어 줍니다 | 없음 — 다 보면 끝 (👀 18/18) |
| 🦌 **무엇이 있을까** | 넉 장 중 **스웨덴에 있는 것** 하나를 찾습니다. 나머지 셋은 세계 지도의 다른 나라 것(🐼 판다 · 🍕 피자 · 🦘 캥거루 …)이라 틀리면 `판다는 중국에 살아요` 하고 알려 줍니다 (10문제) | ⭐ |
| ❓ **퀴즈** | 알아보기에서 읽어 준 것만 물어봅니다 — 수도 · 국기 고르기(🇸🇪 🇳🇴 🇩🇰 🇫🇮) · 다음 왕 · 삐삐 작가 · 사탕 먹는 날 · 스웨덴 말 인사 … 스무 문제 중 열 개가 섞여 나옵니다 | ⭐ |

- 내용은 6~7살 수준으로 골랐지만 **사실은 정확하게** 적었습니다 (열네 개의 섬, 12월 13일 루시아, 평화상만 노르웨이 …).
- 맞히면 설명을 한 줄 읽어 주고 다음 문제로 갑니다. 틀리면 카드가 흐려지고 **까닭**이 뜹니다.
- 한 번에 맞히면 ⭐ 하나. 최고 기록은 놀이별로 남고, 그중 제일 잘한 기록이 세계 페이지 카드에 ⭐ 로 표시됩니다.

### 이야기나 퀴즈를 고치고 싶다면

`js/sweden.js` 위쪽에 셋이 있습니다 — `FACTS`(알아보기 카드), `OTHERS`(다른 나라 것), `QUIZ`(퀴즈).
퀴즈의 `choices` 는 **첫 번째가 정답**이고 화면에서 섞입니다. 카드에 `find: '이름'` 을 적으면 '무엇이 있을까' 보기로도 나옵니다.

### 사진을 바꾸고 싶다면

`sweden/` 폴더에 카드 이름과 같은 `jpg`(가로 800px, 4:3)를 넣고 `FACTS` 의 `img` 에 파일 이름을 적습니다.
`img` 를 지우거나 파일이 없으면 이모지로 대신 나옵니다 (삐삐·스웨덴 말 카드가 지금 그렇습니다).

> **사진 출처를 꼭 적어 주세요.** 지금 사진은 모두 위키미디어 공용에서 가져온 것이라 `sweden/CREDITS.md` 에
> 작가와 라이선스가 적혀 있고, 시작 화면 맨 아래 '출처 보기' 가 그 파일로 갑니다. CC BY / CC BY-SA 사진은
> 출처 표기가 사용 조건이라 사진을 바꾸면 그 표도 같이 고쳐야 합니다. 인터넷에서 아무 사진이나 받아 넣지 마세요.

## ✏️ 글자 쓰기

홈에서 **🇰🇷 한글** 안에 있습니다. **🔤 영어 › 단어 공부** 의 **알파벳 쓰기** 카드도 같은 화면인데,
어느 카드로 들어왔느냐에 따라 보이는 묶음이 다릅니다 — 한글 카드는 자음·모음·숫자·낱말, 영어 카드는 대문자·소문자
(← 도 그 과목으로 돌아갑니다). 연한 글자 위를 **손가락으로 덧그려** 씁니다. 시작 화면에서 무엇을 쓸지 고릅니다.

| 묶음 | 무엇을 | 한 판 |
|---|---|---|
| **자음** | ㄱ ~ ㅎ 열네 자 | 여덟 글자 |
| **모음** | ㅏ ~ ㅣ 열 자 | 여덟 글자 |
| **숫자** | 1 ~ 0 열 자 | 여덟 글자 |
| **낱말** | 다니 · 엄마 · 나비 · 바다 … 스물여덟 개 | 다섯 낱말 (글자마다 대여섯 획이라 짧게) |
| **대문자** | A ~ Z 스물여섯 자 — 영어로 읽어 줍니다 (`A · 에이`) | 여덟 글자 |
| **소문자** | a ~ z 스물여섯 자 — 칸에 십자 대신 영어 공책 가로줄이 그어집니다 | 여덟 글자 |

- **어느 묶음이든 획을 하나씩 안내합니다.** 지금 그을 획만 **파랗게** 보이고 시작점에
  **파란 ①** 이 붙습니다. 한 획을 다 그으면 그 획은 아이가 쓴 진한 선으로 남고 다음 획으로 넘어갑니다.
- **낱말은 글자를 자모로 풀어** 획을 이어 붙입니다 — `아` 는 ㅇ · ㅣ · ㅏ의 가로, 세 획입니다.
- 잘 썼는지는 **얼마나 덮었는지**로 봅니다 — 안내선을 얼마나 덮었고, 밖으로 얼마나 나갔는지.
  삐뚤어도 넉넉하게 통과하도록 잡아 두었습니다.
- **틀려도 벌하지 않습니다.** 획이 안 맞으면 그 획만 사라지고 다시 그으면 됩니다.
  두 번 넘게 안 되면 **▶ 넘어가기** 가 나와서 대신 그어 줍니다 (그 글자는 ⭐ 를 안 받습니다).
- 도구 줄 — **✍️ 어떻게 쓸까**(획을 따라 분홍 선이 지나갑니다) · **🔊 소리** · **🗑️ 다시** · **🎤 목소리**
- **한 번에** 잘 쓴 글자(낱말)마다 ⭐ 하나입니다.

> 획순은 유아 쓰기 교재에서 흔히 쓰는 차례를 따랐습니다. 고치려면 `js/write.js` 위쪽의
> `CONSONANTS` `VOWELS` `NUMBERS` `UPPER` `LOWER` 좌표를 손보면 됩니다. 좌표는 칸을 1×1 로 봤을 때의
> 비율이라 칸 크기가 달라져도 그대로 쓰입니다. 알파벳의 곡선은 `arc()` 로 점을 뽑은 것입니다.
>
> i · j 의 점은 **톡 찍기만 해도** 획으로 받습니다 (다른 획은 찍기만 하면 세지 않습니다).
>
> 낱말은 이 자모 획을 글자 안의 제자리로 옮겨 붙여 만듭니다(`BOXES`). 그래서 **쌍자음(ㄲ)·
> 이중모음(ㅘ)이 든 낱말은 목록에 적어도 조용히 빠집니다** — 그 자모의 획이 아직 없거든요.

## 🧩 글자 만들기

홈에서 **🇰🇷 한글** 안에 있습니다. 그림과 낱말이 나오고 **한 글자가 빈칸**입니다.
**첫소리 → 가운뎃소리 → 받침** 차례로 골라 그 글자를 조립합니다.

- 고를 때마다 빈칸에서 글자가 만들어지는 것이 보입니다 — `?` → `ㄱ` → `가` → `강`
- 아직 차례가 안 온 줄은 흐리게 두어 어디를 눌러야 하는지 헷갈리지 않습니다.
- 오답은 지우지 않고 **흐리게 남긴 뒤** 낱말을 다시 들려줍니다.

| 난이도 | 보기 | 받침 |
|---|---|---|
| 쉬워요 | 3개 중에 | 없는 글자만 |
| 보통 | 5개 중에 | 없는 글자만 |
| 어려워요 | 5개 중에 | 받침까지 (받침이 없으면 **없음** 을 고릅니다) |

**문제로 낼 낱말은 `js/data.js` 의 '한글' 과목 수업에서 그대로 가져옵니다.**
그러니 한글 수업에 낱말을 더 넣으면 이 놀이도 저절로 늘어납니다.
다만 쌍자음(ㄲ) · 이중모음(ㅘ) · 겹받침(ㄳ) 이 든 글자는 5살에게 어려워서 빈칸으로 내지 않습니다.
그런 글자가 든 낱말도 **다른 글자**가 쉬우면 문제로 나옵니다 — `토끼` 는 `토` 가 빈칸이 됩니다.

  색칠 공부 그림을 넣고 칠하거나 사진에 낙서할 때 써요. 지우개는 그린 것만 지우고 사진은 남습니다.
  🗑️ 다 지우기를 누르면 사진도 같이 없어지고, 💾 저장하면 사진과 그림이 합쳐진 한 장으로 저장됩니다.
  사진은 어디로도 보내지 않고 그 화면에서만 씁니다.
- 캔버스 크기는 **창 크기에 맞춰 자동으로 정해집니다** (스크롤 없이 한 화면에 들어오도록)
- 손가락·마우스·펜 모두 됩니다

## 🎈 풍선 터뜨리기

홈에서 **🎨 놀이** 안에 있습니다. 아래에서 올라오는 풍선을 눌러 터뜨립니다.

- **속도를 미리 고르지 않습니다.** 1단계부터 시작해서 한 단계를 끝낼 때마다 다음 단계가 열리고,
  갈수록 풍선이 더 많이 · 더 빨리 올라옵니다.
- 한 단계의 풍선 수는 **12 → 15 → 18 …** 로 세 개씩 늘어납니다.
- **하트 ❤️ 다섯 개**로 시작합니다. 못 누른 풍선이 하늘로 올라가 버리면 하트가 하나 사라지고,
  하트가 다 없어지면 그 판이 끝납니다.
- ⭐ 는 그 판에서 터뜨린 풍선 수입니다 (단계가 넘어가도 이어서 셉니다).
- 높은 단계까지 가 본 적이 있으면 **시작 화면에 시작 단계 버튼**이 생깁니다
  (1단계 / 중간 / 최고 ⭐). 매번 1단계부터 하지 않아도 되고, 마지막에 고른 단계를 기억합니다.
- 최고 기록은 **몇 단계까지 갔는지**가 놀이 페이지의 카드에 남습니다.

## 🧭 미로 찾기

홈에서 **🎨 놀이** 안에 있습니다. 매번 새로 만들어지는 미로에서 **손가락으로 길을 그어** 다니를 간식(🦴 🍎 🧁 …)까지 데려갑니다.
컴퓨터에서는 화살표 키로도 움직입니다.

- 시작 화면에서 판 크기를 고릅니다 — 쉬워요 5×5 · 보통 7×7 · 어려워요 9×9 · 아주 어려워요 11×11.
- 한 판은 미로 **하나**입니다. **되돌아가지 않고 한 번에 찾으면 ⭐** — 손보다 눈이 먼저 가게 하려고요.
  막다른 길에 들어갔다가 나오면 별은 없지만, 계속 찾아서 끝낼 수 있습니다.
  위쪽 점수 자리에 막다른 길에 들어간 횟수(↩)가 보입니다.
- 그은 길을 따라 거꾸로 그으면 길이 지워집니다 (되돌아가기).
- **💡 힌트**를 누르면 정답 길이 잠깐 파랗게 비칩니다. 힌트를 보면 별은 없습니다.
- 간식은 출발점에서 **제일 먼 칸**에 놓입니다. 늘 오른쪽 아래에 있으면 안 보고도 가니까요.
- 한 번에 찾은 적이 있는 판 크기에는 시작 화면 단추에 '⭐ 한 번에!' 가 붙고,
  놀이 페이지 카드에는 **한 번에 찾은 것 중 제일 큰 판**(예: `⭐ 최고 9칸 미로`)이 남습니다.

## 🏃 장애물 피하기

홈에서 **🎨 놀이** 안에 있습니다. 길이 위에서 아래로 흘러오고, 다니는 아래쪽에 서서 **좌우로만** 움직입니다.
내려오는 장애물(🪨 🌵 🐌 🚧 …)을 피해 **깃발 🏁** 까지 가면 다음 단계입니다.

- **움직이기** — 길에 손가락을 대면 다니가 그쪽으로 달려가고, 아래 **◀ ▶ 단추**를 누르고 있어도 됩니다.
  컴퓨터에서는 화살표 키.
- 1단계부터 시작해 깃발에 닿을 때마다 다음 단계가 열리고, 갈수록 길이 더 빨리 흐르고 장애물이 더 촘촘해집니다
  (한 줄에 장애물이 1개 → 3단계부터 최대 2개 → 6단계부터 최대 3개).
  어느 단계든 **옆으로 한 칸씩만 움직여 끝까지 갈 수 있는 길**이 반드시 있습니다.
- **하트 ❤️ 세 개**로 시작합니다. 장애물에 부딪히면 하트가 하나 사라지고(잠깐 깜빡이는 동안은 안 다칩니다),
  하트가 다 없어지면 그 판이 끝납니다.
- 간식(🦴 🍎 🧁 …)을 먹으면 ⭐ 하나 — 위쪽 점수가 그것입니다 (단계가 넘어가도 이어서 셉니다).
- **얼마나 멀리 달렸는지(m)** 를 잽니다 — 단계 칩에 `2단계 · 137m` 처럼 실시간으로 보이고,
  단계를 넘어가도 계속 쌓입니다 (1단계 끝이 80m 남짓).
- **순위표** — 이 기기에서 한 판들 중 멀리 간 순서로 **다섯 개**를 남겨 시작 화면과 결과 화면에 보여 줍니다
  (🥇🥈🥉 4 5). 판이 끝나면 이번 판이 몇 등인지 분홍으로 표시되고, 1등이면 "새 최고 기록! 🏆".
  기기마다 따로 저장되어 다른 기기와는 섞이지 않습니다.
- 풍선 터뜨리기처럼 높은 단계까지 가 본 적이 있으면 **시작 화면에 시작 단계 버튼**이 생깁니다.
- 놀이 페이지의 카드에는 **제일 멀리 간 거리**(예: `⭐ 최고 512m`)가 남습니다.

## 📚 영어 그림책

홈에서 **🇬🇧 영어** 안에 있습니다. 펼친 책의 왼쪽은 그림, 오른쪽은 글이고, 장을 넘기면 영어로 읽어 줍니다.
폰처럼 좁은 화면에서는 그림 → 글 순서로 위아래로 보입니다.

- **📖 읽어 주세요** — 완성된 이야기를 읽어 줍니다. 낱말을 누르면 그 낱말만 다시 읽어 주고,
  분홍색 낱말(만드는 책에서 빈칸이 되는 자리)을 누르면 그림 속 인물이 폴짝 뜁니다.
- **✏️ 내가 만들래요** — 장마다 빈칸이 하나 있고, 그림 셋 중 하나를 고르면 글과 그림이 채워집니다.
  고른 것은 뒤 장에도 이어집니다 (4장에서 마녀를 고르면 그 뒤로 계속 마녀). 빈칸을 채워야 다음 장으로 넘어갑니다.
  다 만들면 **📚 내가 만든 책 보기**가 생겨서 그 책을 다시 읽을 수 있습니다 (책마다 마지막에 만든 것 하나를 기억합니다).
- **💬 뜻** 은 우리말 뜻을 켜고 끕니다. **🎤 목소리**는 다른 놀이와 같은 목소리 고르기입니다.
- 책장에서 읽은 책에는 📖, 만든 적 있는 책에는 ✏️ 표시가 붙습니다.

### 새 책 추가하기

책 한 권은 **`js/books.js` 의 객체 하나 + `books/<책이름>/` 그림 폴더 하나**입니다. 다른 파일은 안 고쳐도 됩니다.
필드 설명과 예시는 `js/books.js` 맨 위 주석에 있고, 첫 책 「Princess Dani」를 그대로 베껴서 고치면 됩니다.

- 글 속의 `{home}` 같은 것이 빈칸입니다. 영어 글에는 고른 낱말(`word`), 우리말 뜻에는 `ko` 가 들어갑니다.
  우리말 조사는 `{monster:이가}` `{place:으로}` 처럼 적으면 받침에 맞게 골라 줍니다.
- 그림은 `books/<책이름>/<이름>.png` 로 넣습니다 (`.png` 가 없으면 `.jpg` 를 찾습니다). 배경은 정사각형이고
  투명이 필요 없으니 **jpg** 로 넣으면 작고, 인물은 **배경이 투명한 png** 로.
  **그림 파일이 없어도 책은 돌아갑니다** — `art` 에 적어 둔 이모지가 대신 나오고, 파일을 넣으면 자동으로 바뀝니다.
- 그림 파일 이름은 `bg` / `actors` 에 적은 이름과 같아야 합니다. 빈칸으로 바뀌는 그림은
  선택지의 `img` 조각이 들어갑니다 (`'{monster}-big'` 에 `img: 'dragon'` 이면 `dragon-big.png`).
